01 · RESEARCH WORKFLOW

Four steps to a benchmark run.

1Select an environmentChoose a map, OHT fleet, workload, and seed.
2Register a methodImplement routing or regional control through the public interface.
3Inspect and runUse the GUI for diagnosis and headless mode for batches.
4Compare outcomesAnalyze throughput, congestion, deadlock, and tail behavior.
02 · RUN THE PLATFORM

Stable command-line entry points.

The same configuration can be validated, visualized, and executed headlessly.

amhslab environment_check
amhslab config_validate --config experiment.json
amhslab gui --config experiment.json
amhslab headless --config experiment.json
03 · CONFIGURE A SCENARIO

Make experimental conditions explicit.

Profiles capture the map, fleet scale, task-generation process, dispatch mode, and reproducibility seed.

{
  "filepath": "maps/benchmark.xlsx",
  "oht_nums": 150,
  "task_generation_method": "fixed_ratio",
  "task_dispatch_mode": "batch",
  "seed": 2026
}
Validate configuration before simulation starts
