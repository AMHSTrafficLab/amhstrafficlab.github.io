PLATFORM OVERVIEW

How AMHSTrafficLab represents and executes traffic.

The platform provides vehicle motion, shared-resource access, task processing, controlled regions, and experiment execution. Researchers supply the routing or regional-control method.

SYSTEM ARCHITECTURE

Scenario configuration and recorded metrics

A scenario fixes the network, fleet, demand, and controlled regions. During a run, the simulator advances vehicle motion, task progress, and shared-resource occupancy while the selected methods observe state and return decisions.

The evaluator uses the same run-level metric definitions for every method.

SIMULATION OBJECTS

Simulation objects

The rail network is directed. Control nodes represent splits and merges, while merge resources coordinate right-of-way where several approaches share a downstream track.

Each OHT executes a transportation task from pickup to delivery. WaterLevelArea objects group parts of the network for occupancy-based admission.
