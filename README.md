# AMHSTrafficLab Website

Website source for the AMHSTrafficLab benchmark platform.

## Local development

Requirements: Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The static export is generated in `dist/client`.

## Pages

- Home
- Platform
- Benchmark
- Validation
- Documentation
